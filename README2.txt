Snoprop manual installation:
1. make a directory to run snoprop
2. copy the input file, e.g. "sample_input_deck2.py" in this directory
3. copy the directory "snoprop" (where the dimulation filed are) in this directory
Your directory should look just like the one in Github.

Snoprop running:
python filename
For example, 
python sample_input_deck2.py
