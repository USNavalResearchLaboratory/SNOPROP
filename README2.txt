Snoprop manual installation:
1. make a directory to run snoprop
2. in this directory, copy the input file, e.g. "sample_input_deck2.py"
3. in this directory, make a subdirectory called "snoprop"
4. copy the simulation files (__init__.py, FileIO.py, NumbaMath.py and simulation.py) in the "snoprop" subdirectory
Your directory should look similar to the one in Github. You need 5 files: the input file and the 4 files in the "snoprop" subdirectory.
The other files are optional.

Snoprop running:
python filename
For example, 
python sample_input_deck2.py
